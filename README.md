Portfolio (CV web) — modèle simple

Ce dépôt contient une version minimale d'un portfolio web (Option A) pour présenter ton CV.

Fichiers ajoutés:
- index.html — page principale (FR)
- assets/styles.css — styles responsives
- assets/script.js — comportement JS minimal

Comment personnaliser
1) Ouvre index.html et remplace les placeholders :
   - Ton Nom (h1)
   - Titre professionnel
   - Paragraphe d'accroche dans la section "A propos"
   - Expériences / Projets / Compétences / Contact
2) PDF du CV : place ton CV nommé "resume.pdf" à la racine du dépôt (ou modifie le lien dans index.html).
3) Images : ajoute des images dans un dossier images/ et référence-les depuis index.html.

Déployer sur GitHub Pages
- Sur la page du dépôt, Settings → Pages → Source → Branch: main / Root → Save.
- Attends quelques minutes, puis ton site sera disponible à l'adresse indiquée.

Prochaine étape que je peux faire pour toi
- Personnaliser le site avec tes informations (je peux remplacer tous les placeholders si tu me fournis : nom, titre, accroche, expériences, projets, compétences, liens sociaux, et un PDF).
- Ajouter une photo, un thème de couleurs, ou activer GitHub Pages pour toi.

Dis-moi si tu veux que je remplace les placeholders maintenant (fournis tes informations) ou si tu préfères modifier toi-même.
